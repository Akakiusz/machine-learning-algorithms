# machine-learning-algorithms

A learning journal for classic machine learning algorithms. Each notebook
takes one algorithm, applies it to a real dataset, and documents what
worked, what didn't, and why.

This is an active work in progress — notebooks are added and revised as I
go through them, not published as finished case studies.

## Purpose

I use this repo to move from "the code runs" to "I can explain why this
result is what it is". Each notebook is expected to answer:

- What does this algorithm actually do to the data?
- Which preprocessing steps does it require, and why?
- How do I evaluate whether the result is any good?
- Where does the algorithm break down?
